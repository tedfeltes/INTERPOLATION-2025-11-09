    Field guide

    1. Prep in Civil 3D

    1. Open the design drawing.
    2. Run EXPORTTOAUTOCAD to explode AECC objects.
    3. Or explode feature lines / alignments needed for stakeout.
    4. Freeze annotation and hatch layers you won’t stake.
    5. Confirm grid coordinates match the Trimble job.

    2. Import in Trimble Access

    1. Copy the DXF into the project folder.
    2. Map → Layer manager → Map files.
    3. Tap file twice so linework is selectable.
    4. Enable Create nodes to stake vertices.
    5. Tap a line or arc → Stakeout.

    Stakeable entities kept by default: LINE LWPOLYLINE POLYLINE ARC CIRCLE POINT INSERT

    Built for stakeout linework

    Trimble Access stakes standard AutoCAD entities from DXF — not Civil 3D proxy objects. StakeDXF decodes DWG, filters to selectable geometry, and writes an ASCII DXF tuned for map stakeout.
