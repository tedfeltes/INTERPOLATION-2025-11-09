    Field guide — no AutoCAD required

    1. Office DWG (one-time)

    1. Save the Civil 3D drawing with PROXYGRAPHICS=1 (typical default).
    2. Leave the DWG on the project network share.
    3. Optional: freeze layers you will not stake.
    4. Confirm grid coordinates match the Trimble job.

    2. Field convert + Trimble

    1. Mount the share and convert via Network path (or CLI).
    2. StakeDXF explodes AECC proxy graphics into stakeable linework.
    3. Copy *_trimble_access.dxf into the project folder.
    4. Map → Layer manager → Map files → selectable → Stakeout.

    Stakeable entities kept by default: LINE LWPOLYLINE POLYLINE ARC CIRCLE POINT INSERT

    How AECC objects are recovered

    Civil 3D custom objects are proprietary, but most DWGs embed a proxy graphic metafile — the last displayed linework. StakeDXF decodes that metafile into standard AutoCAD entities Trimble Access can select and stake. No AutoCAD license is needed on the collector.
